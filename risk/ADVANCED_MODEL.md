# ADVANCED_MODEL.md — the v2 quantitative model

Implementation: `sdk/src/risk-advanced.ts` (single source of truth).
Demo model (static haircuts): `sdk/src/risk.ts` + `risk/RISK_MODEL.md`.
Determinism contract: pure f64 functions, fixed operation order, assets sorted
by symbol, no randomness or wall clock. Golden vectors pin behavior:
`tests/fixtures/advanced-golden.json` (seed 42), regenerated by
`scripts/gen-golden-vectors.ts`.

## Inputs

| input | source |
|---|---|
| quantities, prices, confidence, static advance rates, session, staleness | oracle + institution |
| aligned log-return rows (oldest → newest) | market history (any source; Pyth licensed endpoint in production) |
| policy (z, λ, δ, horizon, multipliers, floors, HF bands) | `AdvancedPolicyParams` (defaults in code; bands mirror the on-chain `RiskPolicy`) |

## 1. Volatility and covariance (EWMA, RiskMetrics-style)

```
σ²ᵢ,ₜ = λ·σ²ᵢ,ₜ₋₁ + (1−λ)·r²ᵢ,ₜ            seed: σ² = r₀²
cᵢⱼ,ₜ = λ·cᵢⱼ,ₜ₋₁ + (1−λ)·rᵢ,ₜ·rⱼ,ₜ        seed: c = rᵢ,₀·rⱼ,₀
```
λ = 0.94 (default). `r` are decimal log returns.

## 2. Shrinkage + PSD repair

```
Fᵢⱼ = ρ̄·σᵢσⱼ   (i≠j),  Fᵢᵢ = σᵢ²          constant-correlation target
Σ = δ·Σ_ewma + (1−δ)·F                    δ = 0.3
```
Then PSD repair: cyclic Jacobi eigendecomposition, negative eigenvalues
clipped to ≥ 0, reconstruction symmetrized. (Sample + shrinkage alone can
still be non-PSD when estimated on short windows.)

## 3. Conservative pricing

```
P⁻ᵢ = max(0, Pᵢ − k·confᵢ)                k = 2 (policy)
```
Pyth's confidence interval is the publisher's own uncertainty — the risk
engine prices the asset at the conservative edge.

## 4. Liquidation-horizon volatility

```
σᵢ = σᵢ,₁d · √(T · m_session)
```
T = liquidation horizon in days (2), m_session ∈ {1.0 open, 1.1 extended,
1.5 closed} — outside US market hours the position cannot be reduced in the
underlying, which stretches the effective response window by 1.5×.

## 5. Effective advance rate

```
ARᵢ = max(AR_floor, AR_static,ᵢ − z·σᵢ)   z = Φ⁻¹(0.99), AR_floor = 20%
```
Interpretation: the static haircut covers issuer/asset risk; the subtracted
term covers the 99th-percentile market move over the response window.

## 6. Concentration — effective number of bets (Meucci 2009)

Project the portfolio onto the covariance eigen-portfolios:

```
p_k = λ_k·(w·v_k)² / (w'Σw)
N = exp(−Σ p_k·ln p_k)
```

Perfectly correlated assets collapse to N = 1; uncorrelated equal-risk
assets give N = asset count. The haircut factor is
`min(1, max(floor, N / N_min))` with N_min = 2 and floor = 0.6, applied to
total eligible value.

## 7. Eligible value and health factor

```
eligibleᵢ = V⁻ᵢ · ARᵢ · (stale ? 0 : 1)        V⁻ᵢ = qtyᵢ·P⁻ᵢ/100
eligible   = Σ eligibleᵢ · concentration_factor
HF (bps)   = floor(eligible·10⁸ / debt_usdc_micros)
```
Hard overlay: any single asset above 40% of gross NAV has its eligible value
scaled to the cap (kept as a blunt guard alongside the statistical measure).

Decisions: HF ≥ credit_hf (2.0) ⇒ ELIGIBLE/COMPLIANT · ineligible_hf (1.5)
≤ HF < credit_hf ⇒ MARGIN_CALL · HF < ineligible_hf ⇒ INELIGIBLE. Stale
oracle ⇒ asset contributes zero.

## 8. Scenario ladder

Deterministic scenarios re-price P⁻ with a common market shock plus
per-symbol idiosyncratic shocks and recompute eligible value and HF with the
same advance rates. The worst scenario is reported. Example output for the
$1M demo portfolio: base HF 1.52 → −10% ⇒ 1.37 → −25% & NVDA −40% ⇒ 1.09.

## Worked check (demo numbers, seeded history)

Conservative NAV $998,920 (0.108% confidence haircut). Vol estimates:
SPYx 0.70%, AAPLx 1.13%, NVDAx 2.57% daily. σ_liq: 0.99%, 1.59%, 3.63%.
Advance rates: 78%, 66%, 52% (NVDA hit hardest — highest vol). Effective bets
2.59 (no concentration haircut, > 2). HF 1.52× ⇒ MARGIN_CALL on $300k debt.

## Determinism

Same inputs always produce the same outputs: seeded RNG only in fixtures, no
Date/random in the engine, symbol-sorted iteration, fixed formulas. The
golden vector test fails on ANY behavioral change to the model.
